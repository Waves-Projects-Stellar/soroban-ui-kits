
### soroban-ui-kit

A scalable and composable UI component library tailored for the Soroban ecosystem. This project provides developers with reusable frontend primitives to rapidly build clean, user-friendly decentralized applications.

---

### ✨ Features

* Wallet connection UI components
* Transaction status modals
* Token display cards
* Form components for contract interaction
* Fully customizable with TailwindCSS

---

### 🧱 Module Breakdown (Contributor-Friendly)

* **Core Components**

  * Buttons, inputs, modals
* **Web3 Components**

  * Wallet connect UI
  * Transaction status
* **Theming System**

  * Dark/light mode
  * Custom design tokens

---

### 🏗 Technical Architecture

* Frontend: Next.js + TypeScript + TailwindCSS
* Contracts: Minimal Soroban contracts for demos
* Scripts: Node.js for testing interactions
